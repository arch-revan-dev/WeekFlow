# Security Policy

**WeekFlow** работает полностью локально на устройстве (offline-first), не содержит рекламы, аналитики и не запрашивает разрешение `INTERNET` в `AndroidManifest.xml`.

## Сообщение об уязвимости / Reporting a Vulnerability

Если вы обнаружили проблему безопасности (например, утечку URI вложений, проблему с `FileProvider` или некорректную обработку импортируемых пресетов):

1. **Не публикуйте** детали уязвимости в открытом Issue до выхода исправления.
2. Откройте приватное сообщение через **Security → Advisories → Report a vulnerability** во вкладке Security репозитория на GitHub.

Мы стараемся рассматривать отчёты о безопасности в кратчайшие сроки и выпускать патч-релиз в разделе Releases.
